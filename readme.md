# BinarySearch

Search (trivial and binary) for the specified key.

The solution consist of three projects:
* _BinarySearchLib_ - library containing `findBinary` and `findTrivial` functions,
* _BinarySearchUnitTest_ - unit test for `findBinary` function,
* _BinarySearchApp_ - sample aplication calling search function.

## Task
Complete the implementation of the search functions: `findTrivial` and `findBinary`.
Check the correctness of the implementation using unit tests.
